# Hamza Hassan — Interactive Developer Portfolio

An interactive, high-performance developer portfolio built with modern web technologies: **React.js, Next.js paradigms, TypeScript, Vite, and Tailwind CSS**. Grounded accurately in Hamza Hassan's resume, this website showcases full-stack development, Gemini AI integrations, financial idempotency, and enterprise DevOps achievements.

## ✨ Key Features & Interactive Innovations

1. **Interactive Experience Lab (Live Demos)**:
   - **AI Resume & Job Match Analyzer (Gemini AI)**: Real-time semantic matching simulator with compatibility scoring, skill gap radar, and AI-generated technical interview questions.
   - **Restaurant Menu Assistant (LLM Companion)**: Natural-language conversational dining assistant with dynamic dietary filtering and simulated context streaming.
   - **Banking Transaction System & Idempotency Visualizer**: Demonstrates fault-tolerant double-entry ledger bookkeeping and shows how unique HTTP idempotency keys prevent double-charging during network interruptions.
   - **Developer Interactive CLI Terminal**: Functional hacker-style shell console supporting commands like `help`, `whoami`, `skills`, `projects`, `experience`, `hire`, `clear`.

2. **Visual & Auditory Polish**:
   - **Interactive Constellation Canvas**: Physics-based HTML5 canvas particle mesh responsive to mouse proximity.
   - **Subtle Web Audio API Sound Synthesizer**: Click, hover, and celebratory chime effects synthesized via browser audio (opt-in mute/unmute toggle in navbar).
   - **Cyber-Luxe Glassmorphism**: Tailored for developers with custom glow accents, dark mode palette, and smooth responsive layout.
   - **Printable Curriculum Vitae**: Built-in resume modal reflecting Hamza's exact CV structure with one-click print / PDF export.

3. **Accurate Resume Showcase**:
   - **Work Experience**: Software Development Intern at NESCOM (Azure DevOps custom extension, REST API integration, Excel work item export).
   - **Education**: Bachelor of Science in Computer Science (BSCS) at Iqra University (CGPA 3.48 / 4.0).
   - **Projects**: All 5 flagship applications with deep-dive architecture inspection modals.
   - **Direct Contact**: Instant email copy, WhatsApp direct link, GitHub link, and contact dispatch form.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended, verified on v22.15)
- npm or pnpm

### Development Server
```bash
npm install
npm run dev
```
The site will run at `http://localhost:5173/`.

### Production Build
```bash
npm run build
npm run preview
```
